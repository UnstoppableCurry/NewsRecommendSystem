项目说明

下面几条同时来自 README.md 和仓库目录，用来说明这个项目是什么、不是什么。

仓库里实际有什么

  • NewsRecommendSystemSpringboot/：Maven 管理的 Spring Boot Web 应用，模板引擎是 Thymeleaf。
  • scala_sparkmlib/：sbt 管理的 Scala 部分，用于模型训练和数据预处理；README 写明已上传训练好的 model。
  • README 写明训练集使用 movie-100 数据；Git 托管限制导致大数据集没有放进仓库。
  • 前端页面基于 layuiAdmin 后台模板，主界面侧栏标题为「新闻推荐系统」。

本页明确不做的事

  • 不在浏览器里模拟推荐接口、评分或爬虫。
  • 不把学习笔记里的指标写成这个项目的评测成绩。
  • 不声称系统已上线、已服务真实用户，或具备生产级效果。
  • 不补充 README 以外的界面截图，也不改写这 5 张图的内容。

README 还写明：非关系型数据没有使用 MongoDB，而是用字符串拼接存在 MySQL；项目并未使用 Spark Streaming、Kafka、HBase、Flink。相似度矩阵曾在单机上长时间计算未完成，作者说明 Spark 面向集群，单机再强也难撑。

架构（按 README 与源码核对）

README 原句把系统写成「springboot + mysql + webmagic + selenium + redis + 部署 spark 环境的 linux（推荐 centos）」。源码与此一致，并分成两部分。

Web 与存储

Spring Boot 1.4、Thymeleaf、MyBatis、Druid、MySQL。用户登录、注册、邮箱验证码、忘记密码都在 Java 控制器里。

实时管道

点击电影后，Jedis 把用户最近行为写入 Redis；再按相似度表取相似条目。README 与控制器注释都把这称作实时推荐管道。

→

离线训练

Scala + Spark 2.3.2 MLlib。仓库里有 ALS、基于标签的冷启动（TF-IDF）、以及按隐向量算电影余弦相似度的脚本。

依赖管理

Scala 部分用 sbt，README 写明冲突处理写在构建配置里。Spring Boot 部分用 Maven，需要自行配置端口、数据库、Redis 和邮箱验证密钥。

ALS 如何接到页面

RecommendMovieController 的 /alsRecommend 通过 SSH（JSch）在 Linux 上执行已打包的 Spark/Java 任务，再把返回的电影 ID 查回 MySQL。这不是浏览器里能完成的步骤。

已实现能力

只列控制器、页面和 Scala 脚本里能直接对上的功能，不补充未实现的产品承诺。

账号与冷启动

登录、注册、图形验证码、邮箱验证码、忘记密码。注册后进入标签选择页（reg2.html），把用户感兴趣的 genres 写入用户表，供后续标签推荐使用。

热门与标签推荐

/getHistoryHotMovies 读历史热门表；/getTheUserGenners 按用户标签取各类 Top 电影。主页 homepage2.html 对应截图里的「热门推荐」「标签推荐」。

实时相似推荐

点击条目会写入 Redis，/getHistoryRating 取出最近一条，再查相似度集合。详情页 2index.html 展示「实时推荐」和「新闻详情」。

ALS 推荐

homepage3.html 调用 /alsRecommend，标题写作「ALS隐语义模型(交叉最小二乘)推荐」。侧栏另有「ALS推荐」入口。

资讯抓取

NewsRecommendSpider 用 WebMagic + Selenium 打开搜索页，按电影标题抓「最新资讯」，再经 Pipeline 写入存储。这是详情页文案的来源，不是独立新闻站点。

离线脚本

ALS 训练与 RMSE 计算、按类型做 TF-IDF 冷启动、用隐向量算余弦相似度并写回 MySQL。这些脚本在 scala_sparkmlib/，需要 Spark 环境。

README 学习笔记摘要

README 大部分是推荐系统课堂式笔记，不是本仓库的评测报告。下面只压缩原文要点，不把它们说成已经跑出来的成绩。

这些条目来自 README 的学习笔记，不是 NewsRecommendSystem 的线上指标或用户调研结论。

笔记中的分类

  • 离线训练：用一段时间的历史数据，迭代周期较长，拟合中长期兴趣。
  • 在线训练：用最近反馈尽快影响下一次推荐；笔记写它更适合广告、电商等对时效要求高的场景。
  • 算法族：人口统计、基于内容、协同过滤（User-CF / Item-CF，以及 SVD、LSA、SVM 等基于模型的方法），再加上混合。

笔记中的评测说法

  • 在线试验提到 A/B 测试；离线试验提到划分训练/测试集并用事先定义的指标比较。
  • 预测误差提到 RMSE、MAE、标准差；Top-N 提到精确率和召回率。
  • 其他维度提到满意度、覆盖率、多样性、惊喜度、信任度、实时性、健壮性和商业目标。
